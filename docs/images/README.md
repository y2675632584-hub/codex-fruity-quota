# Codex 果味额度条宣传素材

- [宣传图](promo.png)：白底黑灰主色，额度图标固定在头像上方，包含今日／累计 Token 悬停示意。
- [功能介绍图](features.png)：连续周额度线、详情横向额度条、重置卡到期、六种配色、低额度提醒和自动更新。
- [生成提示词](image-prompts.json)：内置 image_gen 的本次提示词与历史来源记录。

两张图片均不标注软件版本号。界面示意没有问号按钮，额度图标直接位于头像上方。图中额度、Token 与次数均为演示值，示意图不是实机安装截图。

图标的上方圆弧为 270°，彩色长度相对于这整段可用圆弧计算；例如 75% 为 202.5°、50% 为 135°。底部周额度是独立的浅弧连续线，宽度相对上方圆弧为 42:72，进度按该浅弧长度计算。使用当前项目实际图标几何作为参考。

仅周额度账户的外圈也表示周额度。所有配色在周余量低于 20% 时，周额度线与详情周额度条变红；仅电量绿在外圈剩余 ≤30% 时变红。中央数字表示可用重置次数。Token 提示仅包含今日与累计两行，使用千／万／亿缩写。

对外名称为「Codex 果味额度条」。仓库路径为 `codex-fruity-quota`。宣传素材随项目以 MIT 许可发布。
