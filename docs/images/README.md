# Codex 额度条宣传素材

- [宣传图](promo.png)：白底、黑灰图标；突出固定位置、额度和双平台下载。
- [功能介绍图](features.png)：说明外圈、四点、重置次数、仅周额度账户、自动更新与回滚。
- [生成提示词](image-prompts.json)：使用内置 image_gen 生成和修改；包含最终风格与文字修改提示词。

图中额度是示意数据，界面示意不是实机安装截图。Pro 示例外圈与四点均表示周额度剩余 50%；周额度每用完 25%，一个点变灰。

对外名称为「Codex 额度条」。仓库路径、原有下载包文件名和更新地址保留 `codex-orbit`，使已发布版本继续兼容。
